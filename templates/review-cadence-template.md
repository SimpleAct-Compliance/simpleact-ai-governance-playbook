# Vorlage: Prüfturnus

Was wann läuft, wer es anstößt, und wann es zuletzt gelaufen ist.

Die letzte Spalte ist der eigentliche Zweck: Ein Turnus, der nicht protokolliert wird, ist eine Absicht.

**Angestoßen durch** ist eine Person, keine Kalenderregel. Ein Termin ohne Adressat wird nicht wahrgenommen.

**Automatisiert** ist wichtiger als es aussieht: Eine Vorkehrung, die jemand von Hand anstoßen muss, setzt im Urlaub aus.

## Teil 2: Die ereignisbezogene Prüfung

Sie ist die wirksame. Der Turnus ist eine Untergrenze.

| Auslöser | Bemerkt man ihn von selbst? | Eingerichtete Vorkehrung | Verantwortlich |
|---|---|---|---|
| Zweckbestimmung geändert | meist ja | Meldeweg | |
| **Modellwechsel beim Anbieter** | **nein** | Testsatz, monatlich | |
| neue Datenquelle oder Datenart | oft nicht | Freigabetor bei Änderungen | |
| erweiterter Nutzerkreis | manchmal | Meldeweg | |
| **Aufsicht entfallen oder geschwächt** | **nein** | Kennzahl, monatlich | |
| **Rechtsänderung** | **nein** | abonnierte Quelle, an eine Person | |

Für die drei Nein-Zeilen muss die vierte Spalte gefüllt sein. Sonst sind sie bloß Zeilen in einer Liste.

## Teil 3: Die verkürzte Turnusprüfung

Fünf Fragen je Eintrag. Mehr wird nicht gemacht.

| Eintrag | Einsatzzweck noch wörtlich richtig? | Eigentümer noch zuständig? | Modell/Version geändert? | Geänderte Ausgaben letzter Monat | Nicht gemeldeter Auslöser? |
|---|---|---|---|---|---|
| | | | | | |

Die letzte Frage ist unangenehm und notwendig. Häufige Ja-Antworten sind ein Befund über den **Meldeweg**, nicht über die Person.

Die vierte Spalte gehört mit dem Wert der Vorperiode verglichen. Ein Rückgang gegen Null bedeutet, dass die Aufsicht formal geworden ist.

## Teil 4: Prüfprotokoll

| Datum | Gegenstand | Art | Auslöser | **Bekannt geworden durch** | Ergebnis | Durch |
|---|---|---|---|---|---|---|
| | | ereignisbezogen / turnusmäßig | | Testsatz / Mitteilung / Meldung / Zufall | | |

Die hervorgehobene Spalte ist die lehrreichste des ganzen Modells. Steht dort über mehrere Prüfungen hinweg nur **Zufall**, fehlt kein Feld, sondern ein Verfahren.

Zeilen mit „keine Änderung" sind wertvoll: Die **Reihe** der Prüfungen belegt laufende Pflege. Ein einzelnes aktuelles Protokoll belegt sie nicht — es kann am Vortag entstanden sein.

## Teil 5: Vorkehrungen, die laufen sollten

| Vorkehrung | Eingerichtet | Läuft tatsächlich | Letzter Lauf | Abweichungen |
|---|---|---|---|---|
| Testsatz, Anzahl Eingaben ___ | ja / nein | Anzahl Läufe: ___ | | |
| Aufsichtskennzahl | ja / nein | Monate erhoben: ___ | | |
| Abonnierte Rechtsquelle | ja / nein | zuletzt gelesen: ___ | | |

Die Spalte **Läuft tatsächlich** ist der Unterschied zur Spalte daneben. Ein Testsatz, der eingerichtet ist und nicht läuft, ist keine Vorkehrung — deshalb steht hier eine Zahl und kein Haken.

## Teil 6: Was beim Einrichten schiefgeht

| Grund | Gegenmittel |
|---|---|
| Turnus zu dicht | weniger Fragen, nicht seltener prüfen |
| Turnus zu weit | ereignisbezogene Prüfung ergänzen |
| niemand stößt es an | Termin mit **Person** |
| nach der Erstaufnahme ist die Energie verbraucht | den Turnus **vor** Abschluss der Erstaufnahme einrichten |

Die letzte Zeile ist der häufigste Fehler überhaupt. Nach der Erstaufnahme fehlt genau das Verfahren, das das Ergebnis am Leben hält.
