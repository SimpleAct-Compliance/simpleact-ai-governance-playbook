# Vorlage: Zuständigkeitstabelle

Je System **und je Pflicht** eine Zuweisung. Mit Namen, mit Stundenbudget, mit Vertretung.

Eine Zuständigkeit ohne diese drei ist eine Hoffnung — und wird in zwölf Monaten als Versäumnis der Person gelesen, nicht der Organisation, die sie nicht ausgestattet hat.

**Nicht verhandelbar:** Eigentümer und Prüfer sind nicht dieselbe Person. Steht dort derselbe Name, gehört das in Teil 6 als dokumentierte Abweichung — nicht verschwiegen.

## Teil 2: Stundenbudget

| Person | Rolle in wie vielen Einträgen | Zugewiesene Stunden je Monat | Tatsächlicher Aufwand, geschätzt |
|---|---|---|---|
| | | | |

Die zweite Spalte ist die Diagnose. **Tabelle einmal jährlich nach dieser Spalte sortieren** — wer achtzehnmal als Eigentümer steht, ist überlastet, und das fällt sonst erst bei der Kündigung auf.

Die vierte Spalte vergleicht man mit der dritten. Eine Abweichung um den Faktor drei ist ein Befund, der an die Leitung gehört.

## Teil 4: Laufende Vorkehrungen

| Vorkehrung | Verantwortlich (Person) | Turnus | Automatisiert | Letzter Lauf |
|---|---|---|---|---|
| Testsatz gegen Modellwechsel | | monatlich | ja / nein | |
| Aufsichtskennzahl erheben | | monatlich | ja / nein | |
| Änderungsverlauf der Anbieter lesen | | laufend | — | |
| Befundprotokoll durchsehen, Verschiebungen auswerten | | monatlich | — | |
| Rechtsstand prüfen | | halbjährlich | — | |

Die Spalte **Automatisiert** ist wichtiger als sie aussieht: Eine Vorkehrung, die jemand von Hand anstoßen muss, setzt im Urlaub aus.

Und der Änderungsverlauf geht an eine **Person**, nicht an ein Sammelpostfach. Ein Verlauf, den niemand liest, ist keine Maßnahme.

## Teil 5: Freigabetore und Delegation

| Klasse | Freigabe durch | Delegiert an | Grenze der Delegation | Befristet bis |
|---|---|---|---|---|
| minimal, ohne personenbezogene Daten | | | | |
| minimal, mit personenbezogenen Daten | | | | |
| Transparenzpflicht (Art. 50) | | | | |
| **berührt einen Anhang-III-Bereich** | Geschäftsführung | **nicht delegierbar** | — | — |
| Hochrisiko | Geschäftsführung | **nicht delegierbar** | — | — |
| Art.-5-Treffer | keine Freigabe möglich | — | — | — |

**Grenze der Delegation** ist die Spalte, die fehlt, wenn Delegationen unbemerkt zu weit reichen. Eine Delegation ohne Grenze verlagert auch die Entscheidungen, die nicht verlagert werden sollten.

**Nicht delegierbar** sind außerdem: die Berufung auf Art. 6 Abs. 3, der Weiterbetrieb mit offenem Befund, die Abschaltung nach einem Art.-5-Treffer, und die Zuweisung von Stundenbudgets.

## Teil 6: Dokumentierte Abweichungen

Wenn die Rollentrennung nicht möglich ist — drei Leute, einer macht alles —, gehört das hierhin und nicht verschwiegen.

| System | Welche Rollen zusammengelegt | Wer sieht die Prüfung nach | Entschieden durch | Datum |
|---|---|---|---|---|
| | | | | |

Die abgeschwächte Form ist weniger wert als eine echte Trennung und mehr als nichts. Was nicht geht, ist die Trennung zu **behaupten**: Zwei Namen im Protokoll, wenn eine Person gearbeitet hat, ist ein anderer Befund als ein Name.

## Teil 7: Eskalationswege

| Auslöser | An wen (Person) | Wie schnell | Zuletzt benutzt |
|---|---|---|---|
| Art.-5-Treffer | | sofort | |
| Befund zum dritten Mal verschoben | | mit der Monatsdurchsicht | |
| System läuft mit offenem Befund weiter | | bei Feststellung | |
| Aufsichtskennzahl fällt gegen Null | | mit der Monatsdurchsicht | |
| Vorfall nach Art. 73 AI Act | | sofort | |
| Datenschutzverletzung (Art. 33 DSGVO, 72 h ab Kenntnis) | | sofort | |

Die Spalte **Zuletzt benutzt** ist eine Diagnose. Steht dort nie etwas, obwohl Befunde offen sind, wird der Weg nicht benutzt — und der häufigste Grund dafür ist, dass frühere Eskalationen ohne Ergebnis blieben.

## Teil 8: Nicht delegierbare Entscheidungen der Geschäftsführung

| Entscheidung | Zuletzt getroffen | Durch | Wiedervorlage |
|---|---|---|---|
| wer zuständig ist, mit Stundenbudget | | | |

| ob ein Werkzeug wegen Art. 5 abgeschaltet wird | | | |

Die zweite Zeile bleibt in der Praxis leer, obwohl die Entscheidung getroffen wird — stillschweigend. Sie zu führen ist die Maßnahme, die in einer Prüfung am meisten wert ist.
